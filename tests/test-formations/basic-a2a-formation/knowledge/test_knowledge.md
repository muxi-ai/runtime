# Test Knowledge Base

This is a test knowledge file for validating the formation template system.

## A2A Testing Information

This formation is designed for testing A2A (Agent-to-Agent) communication:

- Registration with external registries
- Discovery of external agents
- Message routing between agents
- Cross-formation communication

## Test Scenarios

1. **Basic Registration**: Agents should register with configured registries
2. **Discovery**: Agents should discover other available agents
3. **Communication**: Agents should be able to send messages to each other
