## Technical Implementation Details

### Cache Storage Structure
```
~/.muxi/{formation_id}/cache/knowledge/
├── {safe_source_path}_{agent_id}.cache
└── ...
```

### Cache File Format
- Binary pickle format containing:
  - `hash`: MD5 hash of source file content
  - `embeddings`: List of embedding data with metadata
  - `timestamp`: Cache creation time
  - `source_path`: Original file path

### Change Detection Mechanism
1. **Content Hash**: Each file has MD5 hash calculated
2. **Smart Loading**: Only regenerates embeddings for changed files
3. **Cleanup**: Removes embeddings for deleted files
4. **Directory Support**: Handles both files and directories
