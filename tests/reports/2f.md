## Test Design Note

During testing, we discovered an important distinction between LLM knowledge and memory system functionality. Initial tests that used common phrases (like "Bob who works at DesignHub") could trigger LLM training data rather than actual memory retrieval. When redesigned with unique, unguessable information (like specific food preferences), the tests clearly demonstrated that the memory system correctly implements user isolation.

This highlights the importance of using unique test data when validating memory isolation features.
