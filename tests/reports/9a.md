## Critical Bugs Fixed

### 1. Webhook URL Bug
**Issue:** `_execute_workflow_async` was overwriting the webhook_url parameter
**Fix:** Preserve passed webhook_url, only fallback to formation config if None
**Impact:** Webhooks now deliver successfully

### 2. JSON Serialization Bug
**Issue:** `MuxiResponse` objects not JSON serializable in webhook payloads
**Fix:** Convert MuxiResponse to dict before webhook serialization
**Impact:** Eliminates webhook delivery failures

### 3. Test Detection Bug
**Issue:** Test expected JSONL format but webhook log used single JSON object
**Fix:** Improved webhook log parsing to handle both formats
**Impact:** Tests now reliably detect delivered webhooks

### 4. Time Estimation Bug
**Issue:** Grossly overestimated task times (28 minutes for simple tasks)
**Fix:** Reduced complexity multiplier from 2 to 0.5
**Impact:** Realistic time estimates for async decisions
