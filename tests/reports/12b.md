## Issues and Resolutions

### Fixed Issues
1. **Webhook URL Missing**: Jobs weren't getting webhook URL
   - Fix: Retrieved from formation config and passed to overlord.chat()
2. **One-off vs Recurring**: Service expected cron for all jobs
   - Fix: Handle both scheduled_for (one-off) and cron_expression (recurring)
3. **Cleanup Error**: formation.shutdown() not async
   - Fix: Removed await, wrapped in try/catch

### Pending Issues
1. **Agent Capabilities**: Same issue as 12a tests
   - Jobs execute but agents can't complete tasks
   - Error: "A2A loop error: Could not find agent with capability 'joke generation'"
   - Need capability-rich test formations

2. **Background Worker Error**:
   - SERVICE_STATUS_CHANGED AttributeError in scheduler worker
   - Impact: None on functionality, only cleanup-related

## Conclusion
Recurring job functionality works correctly at the infrastructure level. Cron expressions are properly parsed (e.g., "every Monday at 8am" → `0 8 * * 1`), jobs are stored and executed on schedule, and webhooks deliver async results. The only failure point is the agent capability gap in test formations, which prevents task completion but doesn't indicate a scheduler problem.
