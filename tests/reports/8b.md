## Critical Fixes Applied (2025-08-20)

### 1. Nested Conversation Context Issue
**Problem**: Enhanced messages were being stored with their context, creating a "matryoshka doll" effect where each message contained all previous messages with their contexts, leading to exponential growth.

**Solution**: Added filtering in `chat_orchestrator.py` to detect and extract clean messages from enhanced messages before adding to conversation context.

### 2. Planning Prompt Confusion
**Problem**: The agent's planning phase received the entire enhanced message (with all conversation context) instead of just the actual user request, causing confusion and delegation loops.

**Solution**: Extract just the actual user request from enhanced messages before passing to `_plan_before_execution()` in `agent.py`.

### 3. Unnecessary Delegation
**Problem**: Agents with the same capabilities were delegating to each other unnecessarily.

**Solution**: Updated planning prompt to include rule: "NEVER DELEGATE TO AGENTS WITH THE SAME CAPABILITIES AS YOU UNLESS THEY HAVE TOOLS THAT YOU NEED BUT DO NOT HAVE."

### 4. Test Timeouts
**Problem**: Tests were timing out after 10 seconds for complex contextual questions.

**Solution**: Extended timeouts to 2 minutes (120 seconds) for all chat calls in 8B tests.
