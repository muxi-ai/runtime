**1. Persona-Level Format Instructions (overlord.py:2116-2123)**
```python
# Added format-specific instructions to _apply_persona() function
if hasattr(self, 'response_format'):
    if self.response_format == "markdown":
        format_instruction = "\n\nFormat your response using proper markdown with headers (# ## ###), bullet points, bold/italic text, and code blocks where appropriate."
    elif self.response_format == "text":
        format_instruction = "\n\nFormat your response as plain text with no markdown formatting, special characters, or HTML. Use simple text formatting like line breaks and spacing."
    elif self.response_format == "html":
        format_instruction = "\n\nFormat your response as valid HTML with proper semantic tags like <h1>, <h2>, <p>, <ul>, <li>, <strong>, <em>, and <code>. Include proper structure and ensure all tags are properly closed. Use clean, readable HTML."
```

**2. Response Post-Processing (overlord.py:6752-6774)**
```python
# Apply response format processing (JSON wrapping, HTML validation)
if result and hasattr(result, "content") and hasattr(self, 'response_format'):
    if self.response_format == "json" and result.content:
        # Wrap the content in JSON format
        import json as json_lib
        result.content = json_lib.dumps({
            "content": result.content,
            "type": "response",
            "format": "json"
        }, indent=2)
    elif self.response_format == "html" and result.content:
        # Validate and fix HTML structure
        try:
            from bs4 import BeautifulSoup
            soup = BeautifulSoup(result.content, 'html.parser')
            result.content = soup.prettify()
        except ImportError:
            pass  # Graceful fallback if BeautifulSoup not available
        except Exception:
            pass  # Keep original content if parsing fails
```

## Technical Architecture

### 🎯 **Design Decisions**

**1. LLM-Based Formatting vs Post-Processing**
- **Chosen:** LLM persona instructions
- **Rationale:** More flexible, context-aware, natural language understanding
- **Benefits:** Simpler code, better quality, easier maintenance

**2. Hybrid Approach**
- **Markdown/Text:** LLM format instructions
- **HTML:** LLM format instructions + BeautifulSoup validation
- **JSON:** Post-processing wrapper (LLM + JSON structure)
- **Reason:** JSON requires valid structure, HTML benefits from validation, text formats rely on LLM understanding

**3. Configuration Layer**
- **Integration:** Uses existing formation YAML configuration
- **Override:** Supports dynamic format changes
- **Backward Compatibility:** Maintains default behavior

### 🔧 **Integration Points**

**1. Formation Configuration**
```yaml
overlord:
  response:
    format: "markdown"  # "json", "text", "markdown", "html"
```

**2. Runtime Override**
```python
overlord.response_format = "json"  # Dynamic format change
```

**3. Response Flow**
```
User Request → Agent Processing → Persona Application (+ Format Instructions) → JSON Wrapping (if needed) → Response
```
