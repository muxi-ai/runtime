## Discovery System Architecture

### FAISS-Based Semantic Search
- **Vector Index**: FAISS for fast similarity search
- **Embedding Model**: Uses formation's configured embedding model
- **Caching**: Embeddings cached to avoid recomputation
- **Relevance Threshold**: Configurable (default 0.7)
- **Multi-Language Support**: Semantic matching works across languages

### Discovery Pipeline
1. **User Request Embedding**: Convert request to vector
2. **Similarity Search**: Find top-k similar SOPs
3. **Relevance Filtering**: Apply threshold and scoring
4. **Priority Resolution**: Handle multiple matches
5. **Mode Selection**: Apply template/guide mode

### Test 7D2: Ambiguous Request Resolution ✅
**Purpose**: Verify intelligent SOP selection for ambiguous requests

**Test Implementation**:
```python
# Ambiguous request
response = await overlord.chat("Handle the issue with the system")

# Context-dependent request
overlord.add_context("Previous: Database connection errors")
response = await overlord.chat("Fix it now")

# Multiple valid SOPs
response = await overlord.chat("Deploy and monitor the new version")
# Could match deployment.md OR monitoring.md
```

**Resolution Strategy**:
1. **Similarity Scoring**: Calculate embeddings distance
2. **Tag Matching**: Boost score for matching tags
3. **Recent Context**: Consider conversation history
4. **Priority Field**: Respect SOP priority settings

**Actual Results**:
- ✅ "Handle the issue" correctly identified as incident-response
- ✅ Context used to select database-recovery SOP
- ✅ Combined SOPs executed for deployment+monitoring
- ✅ Disambiguation completed without user prompts

**Resolution Logic**:
```python
def select_best_sop(matches, context):
    for sop in matches:
        # Base similarity score
        score = sop.similarity
        
        # Boost for tag matches
        if context_tags & sop.tags:
            score *= 1.2
            
        # Boost for recency
        if sop.id in recent_sops:
            score *= 1.1
            
        # Apply priority
        score *= sop.priority
        
    return max(matches, key=lambda s: s.final_score)
```
