## Issues Resolved During Testing

1. **Directory MD5 Calculation**
   - Problem: `_calculate_file_md5()` returned empty string for directories
   - Solution: Skip MD5 for directories, calculate per-file instead

2. **File Limit Bug**
   - Problem: Hardcoded `file_limit=1` only processed 1 file from directories
   - Solution: Use configurable `self.max_files_per_source` (default 5)

3. **Content Hash Missing**
   - Problem: Cache invalidation broken without content hash
   - Solution: Added `content_hash` to chunk metadata

4. **Test Architecture**
   - Problem: Initial tests were unit-testing internal components
   - Solution: Rewrote all tests to use proper chat flow integration

5. **Embedding Dimension Mismatch**
   - Problem: Code assumed 128 dimensions, OpenAI uses 1536
   - Solution: Fixed dimension handling in WorkingMemory
