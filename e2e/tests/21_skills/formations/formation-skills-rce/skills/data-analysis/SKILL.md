# Data Analysis

Use this skill when the user asks for data analysis, charts, or statistical summaries.

## Capabilities
- Load and clean CSV/Excel datasets
- Calculate descriptive statistics
- Generate charts (bar, line, scatter, histogram)
- Create summary reports

## Instructions
1. Understand what the user wants to analyze
2. Identify the data source and format
3. Perform the analysis
4. Present results with clear explanations
