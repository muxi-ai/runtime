# Ticket Handling

Use this skill when managing customer support tickets.

## Escalation Matrix
- Level 1: Basic inquiries (password resets, account info)
- Level 2: Technical issues (bugs, integration problems)
- Level 3: Critical issues (data loss, security incidents)

## Instructions
1. Identify the ticket priority level
2. Follow the appropriate escalation path
3. Document all actions taken
4. Set follow-up reminders for unresolved tickets
